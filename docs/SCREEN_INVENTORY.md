# الشاشات والحالات
|الشاشة|الحالات|
|---|---|
|المصادقة|دخول، تسجيل، استعادة، تغيير كلمة المرور، خطأ، تحميل|
|المكتبة|فارغة، أغلفة حقيقية من المشاريع، بحث، إنشاء، حذف مؤكد|
|الكتابة|لا كتاب، لا فصل، مشهد فارغ، طويل، حفظ، خطأ شبكة، تعارض، استعادة محلية|
|التفاصيل|الخط والحجم والعرض، النسخ، تغيير اسم المشهد|
|العالم|شخصيات وأماكن فارغة/ممتلئة، إنشاء/تعديل/حذف|
|الملاحظات|قائمة، إنشاء، تعديل، حذف|
|التخطيط|حالات ثلاث، أحداث قابلة للتحرير، خط زمني|
|النشر|اختيار كتاب/فصول، تنزيل، معاينة ملف مستورد|
|الأوامر|بحث وتنقل وأوامر سياقية|
|الإعدادات|الحساب والاختصارات وحجم الخط؛ ليست إعدادات المنتج الكاملة|

أضيفت في v2 المسودات المتوازية والعلاقات والتعليقات والحواشي وSprint ونسخ JSON والصور الخاصة. السلاسل المتخصصة والإحصاءات اليومية المتقدمة ما زالت ناقصة؛ انظر FEATURE_STATUS.md.

## V3

- صفحة الرواية: غلاف، نبذة، قصة الرواية، قائمة فصول مباشرة، أدوات مساعدة اختيارية.
- المشاركة والقراءة: أسماء المستخدمين وصلاحيات قارئ/كاتب، نشر فصول محددة.
- حسابي: الاسم واسم المستخدم والنبذة وخيار الملف العام، التطبيقات المتصلة وإلغاء الربط.
- /profile: نبذة الكاتب العامة ورواياته المنشورة، تُخفى عند إيقاف الظهور.
- /read: قراءة فصل منشور بلا حساب، اختيار الفصل التالي؛ لا بيانات تخطيط أو ملاحظات.
- /connect: دخول مِداد، تبديل حساب الموقع، اسم للربط، نطاق الرواية وصلاحية كتابة اختيارية، نجاح/رابط منتهٍ.
