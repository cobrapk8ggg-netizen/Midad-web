## أخطاء اكتُشفت وأُصلحت

1. سياسة SELECT التي تفحص المالك عبر دالة STABLE لم تسمح بـ INSERT RETURNING للرواية الجديدة؛ أُضيف فحص المالك المباشر إلى السياسة، مع اختبار إنشاء فعلي من المتصفح.
2. حالة checkbox النشر كانت ترتد قبل إكمال الشبكة؛ أصبح التحديد يُظهر طلب المستخدم مع حالة انتظار، ويتراجع عند الخطأ ولا يظهر رابط النجاح قبل الحفظ.
3. شريط التنقل السفلي تعدّى عرض الهاتف؛ صُححت الحدود والعرض والتمرير الداخلي، وأعيد اختبار overflow.
4. قاعدة الربط الأولى سمحت بحساب مِداد واحد فقط لكل هوية GPT؛ أُضيف account_id مستقل لكل ربط، وأُجبر اختيار حساب عند تعددها. لا شرط لتطابق البريدين.
