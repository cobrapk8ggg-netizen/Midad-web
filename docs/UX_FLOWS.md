# مسارات الاستخدام
1. إنشاء حساب بالبريد وكلمة المرور ← رسالة تأكيد عند تفعيلها ← دخول ← مكتبة فارغة.
2. رواية جديدة ← عنوان ووصف ← كتاب جديد ← فصل جديد (ينشئ مشهدًا أولًا) ← كتابة ← حفظ ذري ← خروج ← دخول ← اختيار الرواية ← استرجاع النص.
3. التبديل بين المشاهد أو الأقسام أو الخروج ينتظر flush. الفشل يبقي الكاتب في مكانه. إعادة تحميل قسرية تستند إلى المسودة المحلية؛ ليست مزامنة Offline كاملة.
4. نسخة سابقة ← معاينة النصين جنبًا لجنب ← استعادة عبر مسار الحفظ نفسه؛ يحفظ النسخة الحالية أولًا.
5. العالم ← شخصية/مكان ← وصف وخلفية ودوافع ← حفظ ← تعديل أو حذف مؤكد.
6. التخطيط ← حدث ← تفاصيل وتاريخ ← سحب إلى حالة أو اختيار الحالة بلوحة المفاتيح ← خط زمني نصي زمني.
7. التصدير ← كتاب ← فصول محددة ← صيغة ← تنزيل. الاستيراد ← ملف ← معاينة قابلة للتعديل ← فصل هدف ← مشهد جديد.

الأوامر Ctrl/⌘ K؛ التركيز Ctrl/⌘ Shift F؛ Escape للعودة. إدارة الحوارات native dialog تُبقي التركيز داخلها.
