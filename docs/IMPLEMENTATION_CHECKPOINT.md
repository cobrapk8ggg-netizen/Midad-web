# نقطة متابعة التنفيذ

آخر جلسة: 2026-11-11. التطبيق الحقيقي متصل بـSupabase ومنشور على https://midad-writing.vercel.app . لا يُعلن جاهزًا لكل شروط المنتج.

## ما ينبغي أن يبدأ به التنفيذ التالي
1. حل عائق SMTP وحدود البريد، وضبط redirect allowlist للرابط المنشور دون كسر تطبيقات zeus-cloud الأخرى، ثم تسجيل حساب جديد وتأكيده واستعادة كلمة مروره في المتصفح.
2. حفظ تفضيلات المحرر في user_preferences، وإضافة تباعد السطر، وإكمال إدارة الكتب والفصول والمسودات.
3. توسيع entity fields والظهور بالمشاهد والصور الخاصة والعلاقات المحررة، ثم scene/event/arc links وtimeline dependencies.
4. تحسين الهاتف وأهداف اللمس وSafari/WebKit؛ اختبار فعلي على iPad الجيل السابع. لا تستنتج أداء A10 من Chromium.
5. استكمال marks في DOCX/EPUB، تقسيم فصول الاستيراد، EPUBCheck ومعاينة Word، ثم PDF عربي بعد إثبات صحته.
6. اختبارات مخصصة للترتيب والحذف والتعليقات والحواشي والإحصاءات وSprint قبل توسيع الادعاءات.
7. فصل Midad coordinator إلى hooks وشاشات، واعتماد pagination والتحميل عند الطلب بدل تحميل كل مشاهد الكتاب، وIndexedDB بدل localStorage متزامن للمخطوطات الضخمة.
8. baseline سجل migrations البعيد واختبار إعادة تطبيق على قاعدة معزولة، سياسة retention للنسخ، ومراجعة Security Advisors بعد أي توسيع.

لا حساب Demo، ولا أسرار خادم، ولا بيانات مستخدمين حقيقيين ضمن المستودع. حسابا QA مؤقتان يُحذفان بعد نهاية الاختبارات، وملف credentials بقي خارج المستودع. tests تعتمد حسابين منفصلين يعاد توفيرهما عند التشغيل التالي.
