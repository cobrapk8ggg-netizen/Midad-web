# الحركة
150ms للتحويم والضغط والحدود؛ 200ms لدخول الحوار (8px وscale .98)؛ 230ms لرفع الغلاف 5px. لا إعادة تحريك المخطوطة عند الحفظ. وضع التركيز يغير ظهور المحيط ويحافظ على مثيل المحرر. لا حركة حلقية أو تتبع مؤشر. prefers-reduced-motion يوقف الحركة والانتقالات والتحويلات. انتقال spring للوحتي الجانب لم يُنفذ؛ الطي فوري لتجنب تغيير المؤشر.

## v2
انعكاس الزر يمر عند hover مرة واحدة خلال 450ms. لا حلقة. الأغلفة تستجيب بـperspective/translateY، وحقل الدخول يرفع شدة حافته. reduced-motion يوقف الانعكاس والتحويل. حواف الزجاج ثابتة أثناء الكتابة.
