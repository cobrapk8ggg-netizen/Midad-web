# MIDAD · Liquid Obsidian / الإصدار الثاني
سبب رفض الإصدار الأول: التباين السطحي ضعيف، glass فوق الأسود لا يملك شيئًا يعكسه، layout مسطح والحقول بلا شخصية. الأولوية الآن لحضور المادة والعمق عبر طبقات محدودة، لا إكثار blur.

القرار: منضدة كتابة معمارية سوداء، لوح زجاجي عائم بحواف مضيئة، خطوط ضوء فضية منحنية، غلاف كتاب مجسّم أصلي بـCSS، وحبر أبيض سائل. Login يحتوي نموذجًا زجاجيًا ضمن تكوين واحد مع مجسم ورقة/بوابة لا حلقات باهتة. Library فيها رواق ضوء ورفوف أغلفة مائلة قليلًا وظلال حقيقية. المحرر سطح هادئ داخل إطار الأدوات الزجاجية العائمة، cursor ثابت.

Palette: black #000، obsidian #09090b، silver #d8d8e0، white #fff، smoke #a4a4b0. لا أزرق ولا بنفسجي. انعكاسات بدرجات بيضاء حتى 40% على الحافة، body زجاج 5–12%، backdrop blur 18px في ثلاث مناطق أساسية فقط. لا WebGL ولا رسوم حلقية دائمة. تفاعل مؤشر اختياري محدود إلى CSS vars على art فقط؛ reduced motion يلغي التحويل.

الخط IBM Plex Sans Arabic interface وAmiri للمخطوطة. دخول العنوان أكبر، نصوص واجهة الأدوات أوضح، أزرار capsule 44px. مراجعة screenshot على 1440 و1080 و810 و390 قبل إعلان نجاح التصميم.
