# الأمان
لا service_role ولا كلمة مرور في الواجهة أو جداول التطبيق. Publishable Key فقط. Supabase SDK يدير الجلسة والتجديد، وجميع طلبات البيانات تحمل JWT مع RLS. user_metadata لا تستخدم في أي صلاحية. الحماية الفعلية في القاعدة وتعمل حتى مع طلب REST مباشر.

RLS: ملكية auth.uid()، منع نقل المالك، وربط مركب يمنع إلحاق بيانات بحاوية مستخدم آخر. Storage private مع سياسات select/insert/update/delete على uid في المجلد الأول. السجل القديم محفوظ قبل كل تعديل مقبول.

React يهرب نصوص الواجهة. قارئ V4 يستخدم HTML مولدًا من JSON عبر lib/rich-html.ts بقائمة بيضاء صارمة، ولا يعرض HTML المستورد خامًا. Tiptap يعرض schema محددة، استيراد DOCX كنص فقط، وEPUB XML يهرب الرموز. رؤوس nosniff وframe DENY وReferrer Policy وPermissions Policy. CSP شاملة لم تُنفذ. التحقق من أحجام JSON والطول والتدقيق المتقدم يحتاج تحسينًا. بيانات الاستعادة المحلية ليست مشفرة؛ الجهاز المشترك يتطلب انتباهًا، وتُعزل المفاتيح حسب uid.

Security Advisors: لا جداول مِداد معطلة RLS أو بدون سياسات. توجد تحذيرات SECURITY DEFINER مقصودة للدوال العامة والمفوّضة، مفصلة أدناه. تحذيران informational عن جداول zeus_ بدون سياسات (تُترك دون تدخل)، وتحذير عام Leaked Password Protection Disabled؛ يحتاج ضبط Auth مناسبًا للمشروع المشترك. لا ندعي خلو المشروع بأكمله من التحذيرات.

اختبارات RLS الفعلية في docs/rls-results.json. مستخدما QA مؤقتان جرى توفيرهما في Auth بصلاحية إدارية بسبب حد البريد؛ الدخول والبيانات اختُبرت كـauthenticated بالمفتاح العام، لا كـpostgres. هذه ليست برهانًا على تسليم رسالة تأكيد البريد.

## التسجيل المباشر والضيف — الإصدار الثاني
وفق طلب المستخدم، إنشاء حساب مِداد لا يحتاج تأكيد بريد. Edge Function midad-signup تستخدم email_confirm:true على الخادم؛ هذا لا يثبت ملكية البريد، وهو سلوك مقصود. لم تُعطّل سياسة المشروع المشتركة لتطبيقات أخرى. النهاية عامة لأنها تنشئ مستخدمًا، مع تقييد methods/origins وحجم الطلب، وحدود IP/email hashes، ولا تعيد مفاتيح أو تسجل كلمات مرور. خدمة Auth تخزن كلمة المرور وحدها. rate SQL غير قابلة للاستدعاء من authenticated أو anon.
لا يُقبل من العميل user_id أو role أو app_metadata في signup. بيانات الضيف في IndexedDB، دون صلاحيات أو افتراض جلسة. النقل للحساب يستخدم JWT المستخدم الحالي وRLS المعتادة.
النسخ الاحتياطية لا تضم passwords أو tokens أو صور Storage؛ تحتوي أعمال المستخدم فحسب. استعادة backup تتحقق من روابطه وتولّد UUIDs جديدة.

## V3: المشاركة والقراءة وربط ChatGPT

المشاركة لا تمنح الوصول للملاحظات أو عالم الكاتب أو التخطيط. القارئ يرى الفصول الأصلية فقط، والكاتب المشارك يعدّل الفصول مع بقاء user_id للمالك. trigger يمنع تغيير الملكية. النشر العام يمر عبر جدول مخصص لفصول يختارها المالك، وتستبعد واجهات القراءة المسودات البديلة والملاحظات.

تحذيرات Security Advisor المتعلقة بدوال SECURITY DEFINER مقصودة ومراجعة: دالتا القراءة العامة تعيدان فقط بيانات الفصول المنشورة؛ دوال الموافقة مقيدة بـ auth.uid() ورمز عشوائي أحادي الاستخدام؛ دالة البحث عن صديق تعيد الاسم ومعرّفه بالاسم الدقيق ولا تعرض البريد أو نبذة ملف خاص. search_path فارغ. كل وظائف الكتابة الآلية وخريطة الهوية متاحة لـ service_role فقط. لا جداول midad_* بلا RLS.

تبقى تحذيرات المشروع المشترك الخاصة بـ zeus_* وحماية كلمات المرور المسرّبة إعدادات منفصلة لم تُعدّل ضمن هذا العمل. مرجع التحذير المقصود: https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable .

## V4: هوية واكتشاف وتقييم

كل الجداول الجديدة RLS. جداول التصنيف والرف تربط `(project_id,user_id)` بالمالك بمفتاح مركب. لا يستطيع B عرض صفوف A الخاصة أو تزوير روابطه/صوره/متابعته. دوال حفظ الملف والتصنيف SECURITY INVOKER وذرية؛ رابط غير صالح لا يترك تعديلًا جزئيًا. صور الملف تقبل مسارًا يبدأ بمعرف مالكه، والسياسة العامة تتحقق من بادئة المالك بنفسها أيضًا.

Bucket midad-assets **خاص**. سياسة عامة محددة تسمح فقط بالصورة والغلاف المشار إليهما في ملف public، أو غلاف رواية معروضة/منشورة؛ لا توسعة عامة لكل مجلد المستخدم. توقيع الزوار 60 ثانية. إخفاء الملف يمنع إصدار روابط جديدة؛ الرابط الصادر سابقًا يبقى صالحًا حتى انتهاء مدته، ولا يمكن محو صورة حفظها زائر بالفعل.

`midad_catalog` و`midad_writer_profile` و`midad_public_chapter_index` و`midad_read_public_chapter` عامة عن قصد مع search_path فارغ وشروط نشر صريحة وقائمة حقول محددة؛ لا ترجع البريد أو القصة الخاصة أو الملاحظات. الكتالوج يحجب اسم/معرف/صورة الملف الخاص. الصفحات العامة لا تستخدم shared user cache. التقييمات تعاد كمتوسط/عدد فقط؛ قائمة القراءة خاصة بالجلسة. الكاتب والمحرر لا يقيمان عملهما؛ تقييم سابق لمحرر جديد يُستبعد من التجميع.

مراجعة Advisor بتاريخ 2026-11-12: تحذيرات تنفيذ الدوال definer العامة والمفوّضة باقية عن قصد وتوثق [هنا](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable). إشعارات zeus_* وحماية كلمات المرور المسرّبة تخص المشروع المشترك ولم تُعدّل. لا نعالج إغلاق واجهات القراءة العامة باعتباره إصلاحًا لهذه الإشعارات.

الخطوط والألوان والروابط في rich HTML مقيدة بقوائم؛ كل نص وattribute مهرب. اختبارات XSS/unsafe CSS ضمن writer-v4.test.ts. لا زعم بتدقيق أمني شامل، أو مكافحة إساءة اجتماعية كاملة. تفاصيل الاختبارات الحديثة في V4_TEST_REPORT.md؛ حسابا V4 أنشئا عبر مسار التسجيل الفعلي بلا تأكيد بريد.
