## إصلاحات ظهرت أثناء التحقق

توقع رقمي كان يفترض «١» بينما locale المتصفح يعرض «1»؛ صُحح ليقبل الشكلين مع بقاء شرط وجود رواية واحدة. اختيار فقرة بلوحة المفاتيح شمل فقرتين، فحدد الاختبار الفقرة الأولى صراحة لفحص خصائصها، دون تغيير اختبار النص المحفوظ. أصلح تحميل صور عامة متأخرة بعد انتهاء الرابط الموقع بإعادة إصدار الرابط عند فشل تحميله بعد انتهاء مدته.

## حدود معلنة

Safari على iPad 2019 الفيزيائي غير متاح؛ اختبارات المقاسات Chromium. تصدير DOCX/EPUB فُحص بنيويًا ومحتواه، ولم تُراجع هذه الإضافة داخل Word/Apple Books أو EPUBCheck. لا مزامنة CRDT لحظية؛ المشاركة الحالية تحفظ مع حماية تعارض النسخ. لا رسائل خاصة أو إشعارات أو تعليقات قراء أو نظام بلاغات ومراجعة محتوى حتى الآن. التقييم حساب واحد، دون ادعاء التحقق من كون كل حساب شخصًا مستقلًا. استعادة كلمة المرور بالبريد ما زالت تحتاج تحقق SMTP مستقلًا.

التحقق المنشور وسجل الإصدار يُضافان بعد النشر؛ نتائج هذا الملف أعلاه تخص البناء المحلي المتصل بقاعدة Supabase الحقيقية.
